# チェックリスト集

## 一次情報チェック

- [ ] 公式ドキュメント/仕様が確認できている
- [ ] 実装（ソース/挙動）を確認できている
- [ ] ブログ/記事は補助情報として扱っている
- [ ] AI生成物や経験則を、根拠ではなく仮説/補助情報として扱っている
- [ ] 根拠種別、信頼度、再確認条件を記録している

## 検証チェック

- [ ] 再現手順が最小構成になっている
- [ ] 環境（バージョン）が固定されている
- [ ] ログ/証跡が採取されている
- [ ] 共有する証跡はマスキング済み（秘密情報・個人情報を含まない）

## 意思決定チェック（再検証性）

- [ ] 前提/スコープ境界（何を含み、何を含まないか）を明記した
- [ ] 代替案（採用しなかった案/理由）を記録した
- [ ] 未確定点を結論に混ぜず、相談または再調査対象として分離した
- [ ] 次回の再確認トリガ（バージョン更新、仕様改訂、運用差分など）を明記した

## AI利用チェック

- [ ] 機密情報を入力していない
- [ ] 出力を一次情報/検証で裏取りしている
- [ ] AIが提示したリンク、引用、数値、コードの実在性を確認している
- [ ] レビュー観点（前提/例外/互換性/影響）で確認している
- [ ] AI出力の採用/不採用理由と最終文責者を記録している
