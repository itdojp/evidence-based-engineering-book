# チェックリスト集

## 一次情報チェック

- [ ] 公式ドキュメント/仕様が確認できている
- [ ] 実装（ソース/挙動）を確認できている
- [ ] ブログ/記事は補助情報として扱っている

## 検証チェック

- [ ] 再現手順が最小構成になっている
- [ ] 環境（バージョン）が固定されている
- [ ] ログ/証跡が採取されている
- [ ] 共有する証跡はマスキング済み（秘密情報・個人情報を含まない）

## 意思決定チェック（再検証性）

- [ ] 前提/スコープ境界（何を含み、何を含まないか）を明記した
- [ ] 代替案（採用しなかった案/理由）を記録した

## AI利用チェック

- [ ] 機密情報を入力していない
- [ ] 出力を一次情報/検証で裏取りしている
- [ ] レビュー観点（前提/例外/互換性/影響）で確認している
